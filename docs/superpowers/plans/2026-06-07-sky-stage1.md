# Sky Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat background with a procedural day–night sky (sun disk, stars + Milky Way, moon) and add real moonlight, all driven by the existing time-of-day controller.

**Architecture:** A `sky.gdshader` (`shader_type sky`) paints the whole cycle from uniforms. A `Sky` resource using a `ShaderMaterial` of that shader becomes the Environment background. `sun_controller.gd` (the existing time-of-day "conductor") feeds the shader `sun_dir` / `moon_dir` / `daylight` each frame and drives a new `Moon` DirectionalLight3D that lights the scene at night.

**Tech Stack:** Godot 4.6, GDScript, Godot sky shader. Verification: `godot` MCP (`run_project` / `get_debug_output`) for load/compile errors, **plus in-engine USER TESTS** across day and night (the running game can't be screenshotted headless).

## Task 1: Create the sky shader

**Files:**
- Create: `sky.gdshader`

- [ ] **Step 1: Write the shader**

Create `sky.gdshader` with exactly:

```glsl
shader_type sky;
render_mode use_debanding;

// Set every frame by sun_controller.gd
uniform vec3 sun_dir = vec3(0.0, 0.3, 1.0);   // direction TOWARD the sun
uniform vec3 moon_dir = vec3(0.0, 0.3, -1.0); // direction TOWARD the moon
uniform float daylight : hint_range(0.0, 1.0) = 1.0;

uniform vec3 day_zenith : source_color = vec3(0.17, 0.35, 0.72);
uniform vec3 day_horizon : source_color = vec3(0.64, 0.76, 0.93);
uniform vec3 night_zenith : source_color = vec3(0.010, 0.015, 0.040);
uniform vec3 night_horizon : source_color = vec3(0.030, 0.050, 0.100);
uniform vec3 sun_color : source_color = vec3(1.0, 0.95, 0.85);
uniform vec3 moon_color : source_color = vec3(0.70, 0.78, 0.95);
uniform float sun_size : hint_range(0.0, 0.2) = 0.015;
uniform float moon_size : hint_range(0.0, 0.2) = 0.030;
uniform float star_amount : hint_range(0.9, 1.0) = 0.985; // higher = fewer stars
uniform float milky_way_strength : hint_range(0.0, 1.0) = 0.6;

float hash13(vec3 p3) {
	p3 = fract(p3 * 0.1031);
	p3 += dot(p3, p3.zyx + 31.32);
	return fract((p3.x + p3.y) * p3.z);
}

void sky() {
	vec3 dir = normalize(EYEDIR);
	float up = clamp(dir.y * 0.5 + 0.5, 0.0, 1.0);

	// --- Day gradient + sun ---
	vec3 day = mix(day_horizon, day_zenith, pow(up, 0.6));
	float sd = dot(dir, normalize(sun_dir));
	float sun_disk = smoothstep(1.0 - sun_size, 1.0 - sun_size * 0.5, sd);
	float sun_glow = pow(max(sd, 0.0), 120.0) * 0.6;
	day += sun_color * (sun_disk * 8.0 + sun_glow);

	// --- Night gradient + stars + Milky Way + moon ---
	vec3 night = mix(night_horizon, night_zenith, pow(up, 0.8));

	// Stars: quantise the direction, random per cell, only above the horizon.
	vec3 cell = floor(dir * 250.0);
	float rnd = hash13(cell);
	float star = step(star_amount, rnd);
	float twinkle = 0.65 + 0.35 * sin(TIME * 3.0 + rnd * 120.0);
	float star_fade = smoothstep(0.02, 0.30, dir.y);
	night += vec3(1.0) * (star * twinkle * star_fade);

	// Milky Way: a soft noisy band across the sky.
	float band = smoothstep(0.22, 0.0, abs(dot(dir, normalize(vec3(0.7, 0.25, 0.6)))));
	float band_noise = hash13(floor(dir * 70.0));
	night += vec3(0.05, 0.06, 0.10) * band * band_noise * milky_way_strength * star_fade;

	// Moon: bright disk + soft glow.
	float md = dot(dir, normalize(moon_dir));
	float moon_disk = smoothstep(1.0 - moon_size, 1.0 - moon_size * 0.5, md);
	float moon_glow = pow(max(md, 0.0), 180.0) * 0.4;
	night += moon_color * (moon_disk * 3.0 + moon_glow);

	COLOR = mix(night, day, daylight);
}
```

And an internal var near `_sky_material`:

```gdscript

```

In `_resolve_targets()`, add:

```gdscript

```

- [ ] **Step 4: Compute the moon arc and drive light + sky**

Add this helper to `sun_controller.gd`:

```gdscript
func _moon_progress(hour: float) -> float:
	# 0 at nightfall, 1 by sunrise — a single sweep across the night.
	var span := (24.0 - night_hour) + sunrise_hour
	if span <= 0.001:
		return 0.0
	var into := hour - night_hour if hour >= night_hour else (24.0 - night_hour) + hour
	return clampf(into / span, 0.0, 1.0)
```

In `_apply_time_of_day()`, after the sky `sun_dir`/`daylight` block from Task 3,
add:

```gdscript
	var night_amt := 1.0 - daylight
	var moon_t := _moon_progress(hour)
	var moon_height := sin(moon_t * PI)
	var toward_moon := Vector3(lerpf(-0.7, 0.7, moon_t), maxf(moon_height, 0.05) * 1.4, -1.0).normalized()
	if _sky_material != null:
		_sky_material.set_shader_parameter("moon_dir", toward_moon)
	if _moon != null:
		_moon.light_color = moon_color
		_moon.light_energy = max_moon_energy * night_amt * clampf(moon_height + 0.15, 0.0, 1.0)
		_moon.shadow_enabled = _moon.light_energy > 0.02
		_moon.look_at(_moon.global_position - toward_moon, Vector3.UP)
```

(The light travels opposite to `toward_moon`, so it looks toward `-toward_moon`.)

- [ ] **Step 1: Apply tuning from the user's reports**

Based on the USER TESTs, set tuned values. Shader params go on the `SkyMat`
sub-resource in `main.tscn` as `shader_parameter/<name>` lines, e.g.:

```
[sub_resource type="ShaderMaterial" id="SkyMat"]
shader = ExtResource("40_sky")
shader_parameter/star_amount = 0.985
shader_parameter/milky_way_strength = 0.6
shader_parameter/moon_size = 0.03
shader_parameter/day_zenith = Color(0.17, 0.35, 0.72, 1)
```

Common adjustments:
- Too many/few stars → raise/lower `star_amount` (higher = fewer).
- Milky Way too strong/weak → `milky_way_strength`.
- Moon too big/small or dim → `moon_size`, `max_moon_energy` (on the `Sun` node).
- Night too bright/dark indoors → `max_moon_energy` and, optionally, raise
  `ambient_light_sky_contribution` on `Env` a touch (e.g. 0.1) for sky tint.
- Day sky colour → `day_zenith` / `day_horizon`.

Re-run + re-ask until day and night both read well.
